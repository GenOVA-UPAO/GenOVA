# T3 — Workspace en blanco en mobile (WS-01, ALTA)

Hallazgo: `sdd/audits/2026-07-16-auditoria-visual-e2e.md` (WS-01) — en
`/workspace/:id` a 375px el toggle "Chat | Preview / Code" existe pero el
contenido queda en blanco (~186 contenedores con altura 0; el iframe existe
en el DOM con 375x150 pero no pinta nada).

## Diagnóstico

Cadena de altura rota entre `<main class="flex min-h-0 flex-1 flex-col">`
(`frontend/src/app/layout/shells/app-layout.ts`) y los paneles mobile con
`absolute inset-0` de `ova-edit-view.component.html`.

Los custom elements de Angular son `display: inline` por defecto (no hay
UA stylesheet que los ponga en `block`). Ni `gn-ova-workspace-page`
(`ova-workspace-page.component.ts`) ni `gn-ova-edit-view`
(`ova-edit-view.component.ts`) ni `gn-ova-creation-view`
(`ova-creation-view.component.ts`) declaraban `host: { class: "flex ..." }`,
así que aunque sus templates internos usan `flex flex-col flex-1 min-h-0`,
esos `flex-1` no tenían efecto: su padre inmediato (el propio host, inline)
no es un contenedor flex, así que no propaga altura hacia abajo.

En desktop (`≥sm`) el bug no se notaba porque el panel `#container` usa
`hidden sm:flex flex-1` en flujo normal con contenido de altura intrínseca
(chat + divisor + panel OVA), que "empuja" altura aunque el padre colapse a 0
en algunos casos, y los navegadores toleran mejor overflow visual ahí. En
mobile, los paneles `absolute inset-0` dependen 100% de que su padre
`.flex-1.overflow-hidden.mt-2.relative` tenga altura real — si esa cadena
colapsa a 0, los `absolute inset-0` heredan altura 0 y todo queda en blanco.

Se confirmó además que las dos rutas del workspace
(`/workspace/:id` y `/ova/job/:jobId/workspace`, ambas resueltas por
`OvaWorkspacePageComponent`) activan siempre la rama `fullBleed` de
`AppLayout` (`router.url.includes("/workspace/")`), o sea que ambas dependen
de la misma cadena `<main flex-1>` → `gn-ova-workspace-page` →
`gn-ova-edit-view` / `gn-ova-creation-view`.

## Cambios

- `frontend/src/features/ova-workspace/pages/ova-workspace-page.component.ts`
  — añadido `host: { class: "flex min-h-0 flex-1 flex-col" }`.
- `frontend/src/features/ova-workspace/components/editor/ova-edit-view.component.ts`
  — añadido `host: { class: "flex min-h-0 flex-1 flex-col" }`.
- `frontend/src/features/ova-workspace/components/creation/ova-creation-view.component.ts`
  — añadido `host: { class: "flex min-h-0 flex-1 flex-col" }` (mismo fix,
  vista de creación `/crear` comparte `OvaWorkspacePageComponent` como host y
  tenía el mismo problema latente).

Con estos tres hosts convertidos en flex items/contenedores, la cadena
`main.flex-1` → `gn-ova-workspace-page` → `gn-ova-edit-view`/`gn-ova-creation-view`
→ `div.flex-1.min-h-0` (root de cada template) queda completa y los paneles
`absolute inset-0` en mobile reciben altura real de su padre `relative`.

No fue necesario tocar `absolute inset-0` de los paneles mobile: con la
cadena de altura reparada, el padre inmediato ya tiene altura no-cero, así
que `inset-0` funciona correctamente sin pasar a flujo normal (opción más
simple, sin tocar más superficie de la necesaria).

No se tocó `app-layout.ts` (ya tenía `flex min-h-0 flex-1 flex-col` correcto
en `<main>`) ni los componentes intermedios `gn-workspace-chat-panel` /
`gn-workspace-ova-panel` (fuera de alcance, no forman parte de la cadena
rota).

## Verificación

- `pnpm --filter frontend lint` → verde, sin warnings.
- `pnpm --filter frontend typecheck` (`ngc -p tsconfig.app.json --noEmit` +
  `ngc -p tsconfig.spec.json --noEmit`) → verde.
- Verificación visual (viewport 375px, `/workspace/:id`) queda a cargo del
  hilo principal (auditoría E2E).

## Riesgo / alcance

- Cambio quirúrgico: 3 líneas `host: { class }` en 3 archivos `.ts`, sin
  tocar HTML ni lógica.
- Desktop (`≥sm`) no debería verse afectado: los paneles ya estaban en flujo
  normal con altura intrínseca: el `host: flex` solo hace explícito lo que el
  layout ya asumía implícitamente.
- Vista de creación (`/crear`, sin `ovaId`) usa el mismo
  `OvaWorkspacePageComponent` como host y ahora también hereda el fix.
